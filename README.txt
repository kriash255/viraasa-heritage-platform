VIRAASA UPDATE - what to do (5 steps)

2. Deploy to Netlify: upload index.html, the media/ folder (the client's video, audio, hero image) and admin/ file.
3. Open the admin panel -> Login -> Settings -> RUN SYSTEM CHECK (all lines must show a green tick).
4. Add Place -> IMPORT JSON -> choose import/hatkeshwar-mahadev-temple.json -> Save Place.
   (Review the Gujarati/Hindi text with a native speaker first. The audio is placed in the English slot.)
5. Open the website: the video, audio, hero image and all 3 bio tabs should now show.

Limits written inside the admin panel: video 50 MB / 3 min, audio 25 MB / 10 min, images 10 MB.
